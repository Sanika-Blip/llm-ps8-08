# Product Description Writer (LLM PS8)

**Problem statement:** Online sellers need appealing listings. This app generates a product title, 3 benefit bullets and a 60-word description from a product name, features and target audience.

## Run
```
pip install -r requirements.txt
# create .env containing: GEMINI_API_KEY=your_key
streamlit run app.py
```
Free API key: https://aistudio.google.com/apikey

Stack: Python, Streamlit, Gemini 2.5 Flash.
